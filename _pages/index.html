Apicurio Registry

High performance, runtime registry for API designs and schemas

Apicurio Registry is an open source schema registry and API registry for platform and data teams. It stores, versions and governs Avro, Protobuf and JSON Schema schemas for Apache Kafka, and OpenAPI, AsyncAPI and GraphQL API definitions, and works with existing Confluent Schema Registry clients.

It is also an agent registry and MCP registry for AI systems: store A2A agent cards, MCP tools, prompt templates and model schemas, and let agents discover them. Apicurio Registry for AI agents.
